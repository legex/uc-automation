Template Guidelines

📝 General Guidelines:

  • • All templates are in CSV format
  • • First row contains column headers - do not modify them
  • • Required fields are marked with asterisks (*)
  • • Optional fields can be left empty
  • • Remove sample data before uploading your actual data

⚠️ Important Notes:

  • • Ensure proper CSV formatting (comma-separated values)
  • • Use UTF-8 encoding to avoid character issues
  • • Maximum file size: 10MB
  • • Test with a small batch before processing large files
  • • Keep backups of your data before batch operations

✅ Best Practices:

  • • Validate data format before upload
  • • Use consistent data formatting across all rows
  • • Double-check critical fields like usernames and extensions
  • • Review result files after batch operations
  • • Contact support if you encounter repeated errors
